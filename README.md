# Weather-App
Weather App is a web application that provides real-time weather information for any city worldwide. The app fetches live weather data from a weather API and displays details such as temperature, humidity, wind speed, and overall weather conditions in a clean and user-friendly interface.

🚀 Features

🌍 Search weather by city name

🌡️ Display current temperature

💧 Show humidity levels

🌬️ Wind speed information

🌥️ Weather condition (Cloudy, Sunny, Rainy, etc.)

📅 Date and time display

📱 Fully responsive design

⚡ Real-time API integration

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript (or React if used)

API: OpenWeatherMap API (or mention the API you used)

Styling: CSS / Tailwind / Bootstrap

⚙️ How It Works

User enters a city name.

The app sends a request to the Weather API.

The API returns real-time weather data in JSON format.

The application parses the data and dynamically updates the UI.

The app uses asynchronous JavaScript (fetch / async-await) to handle API calls efficiently.

🎯 Purpose of the Project

This project was built to:

Practice API integration

Strengthen JavaScript asynchronous concepts

Improve DOM manipulation skills

Enhance UI/UX design

Work with JSON data handling
